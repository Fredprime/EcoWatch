# 24 — Glossary and Domain Language

| Term | Meaning in EcoWatch |
|---|---|
| Observation | Original report, measurement, sensor record, image-derived observation or imported record. |
| Evidence asset | File or structured data object supporting an observation or case. |
| Provenance | Information about where evidence came from, how it was acquired and how it was processed. |
| Case | Managed investigation or response record concerning a suspected environmental condition or event. |
| Evidence relationship | A typed link between observations/assets or an observation and a case. |
| Correlation | A method for identifying records that may be related; it does not establish truth or cause. |
| Environmental relationship | A domain-specific link such as upstream/downstream, pathway or habitat connectivity. |
| Baseline | Defined reference condition/period used for comparison. |
| Indicator | A measured or derived variable used to describe an environmental condition. |
| Analysis run | Reproducible record of inputs, method, parameters and outputs. |
| Intervention | Planned or actual response activity linked to a case. |
| Output | Immediate product of an activity, such as an area treated. |
| Outcome | Change in an environmental or social indicator. |
| Recovery | Sustained improvement supported by appropriate evidence and criteria. |
| Verification | Review of whether a claim or outcome is supported by specified evidence. |
| Uncertainty | Known limits in precision, completeness, method or interpretation. |
| Idempotency | Repeating the same request safely without creating duplicate records. |
| PostGIS | PostgreSQL extension for storing, indexing and querying spatial data; proposed for EcoWatch. |
| PWA | Progressive Web App; a web application that can provide selected offline capabilities. |

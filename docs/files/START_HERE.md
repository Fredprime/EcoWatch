# EcoWatch Documentation Package (v0.8)

This folder holds the merged documentation baseline for EcoWatch. It combines the earlier full draft, the revised package and the SignalWeave project.

Start with `00_README_and_Documentation_Guide.md`, then documents 01 to 03 for the project definition and scope. Document 22 describes the SignalWeave correlation engine and offline-first collection layer, and document 23 records exactly what was merged, changed and left out. Document 19 holds recommendations, 20 the UI register, 21 the documentation standards.

**Approved:** five-stage operating model; hybrid collection; PostgreSQL; design-first with no build prompts; full working system in phases (no pilot); no example or demo data; open Public area with no login or accounts; Staff (workers and analysts) and Admin sign-ins; staff submissions tied to the staff ID; reporter safety and anonymity measures; SignalWeave merged as the correlation engine and offline collection layer.

**Deferred:** Supabase and Firebase evaluation (document 18).

**Open decisions to make:** PostGIS; local-only correlation (DR-036); provisional clusters as Staff-only (DR-040); whether any live demonstration may use temporary records (DR-041); providers and frameworks; AI model; initial areas of operation; indicators; permission differences between workers and analysts.

This is a design baseline, not evidence of implementation, deployment, scientific validation, legal compliance or environmental recovery.

# EcoWatch Documentation Package

This archive contains the initial documentation baseline for EcoWatch.

Start with `00_README_and_Documentation_Guide.md`, then read documents 01–03 for the project definition and scope.

**Approved:** five-stage operating model; hybrid data collection; anonymous and registered submissions; separate temporal fields; PostgreSQL; documentation-first approach; no build/master prompts.

**Deferred:** Supabase and Firebase evaluation. See `18_Deferred_Platform_Evaluation_Brief.md`.

**Not yet approved:** pilot location, PostGIS, frontend/backend frameworks, hosting, storage provider, AI models and exact environmental indicators.

This is a design baseline, not evidence of implementation, deployment, scientific validation, legal compliance or environmental recovery.

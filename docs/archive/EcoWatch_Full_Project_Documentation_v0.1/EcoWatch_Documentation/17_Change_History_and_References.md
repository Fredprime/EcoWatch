# 17 — Change History and References

**Status:** Initial record for the documentation baseline.

## 1. Document control

Project documentation should use:
- Stable document identifiers.
- Version numbers.
- Status.
- Prepared or revised date.
- Named owner or responsible role once assigned.
- Change summary.
- Related decision records.

## 3. Change management

When a decision changes:
1. Record the reason.
2. Update the decision register.
3. Identify affected documents and requirements.
4. Update diagrams, data definitions and test cases where necessary.
5. Record the revision date and summary.
6. Review whether the change affects cost, privacy, security, science or pilot scope.

## 4. Source and evidence register

The project should maintain a source register for external environmental datasets, scientific methods, platform documentation, legal guidance and standards.

For each source record:
- Source title and organisation.
- URL or document reference.
- Date accessed.
- Licence or use terms.
- Geographic and temporal coverage.
- Method and known limitations.
- Which EcoWatch decision or analysis uses it.

## 5. Candidate reference sources to investigate

These are starting points for research, not proof that a particular dataset is suitable or freely reusable:

- USGS Landsat missions and data documentation.
- Copernicus Sentinel data and documentation.
- Google Earth Engine documentation and data catalogue.
- Global Forest Watch data and methodology.
- Ghanaian environmental and water-related agencies' published datasets and reports.
- Peer-reviewed research on Ghanaian watersheds, mining impacts, water quality, land-use change and restoration.
- Official PostgreSQL documentation.
- Official PostGIS documentation.
- Official platform documentation for any hosting, authentication or storage provider eventually considered.

Before using a source, check current availability, access conditions, licence, resolution, coverage, processing level and suitability for the intended environmental question.

## 6. Scientific reference quality

Prefer primary datasets, official technical documentation, peer-reviewed studies and qualified local expertise. News reports and social-media posts may help identify leads but should not substitute for scientific measurements or authoritative records.

## 7. Verification note

This initial package records project decisions and design proposals. It does not claim that datasets have been downloaded, permissions obtained, models validated, software implemented, security tested or environmental outcomes verified.
